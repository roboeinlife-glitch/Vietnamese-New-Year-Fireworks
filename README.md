## ✨ Đặc Điểm Nổi Bật

### 🎇 **Hiệu Ứng Pháo Hoa**
- **4 lớp nổ liên tiếp** với hiệu ứng trail mượt mà
- **Vật lý thực tế**: trọng lực, ma sát, chuyển động parabol
- **Màu sắc đa dạng**: 15 màu pháo hoa ngẫu nhiên

### 🌸 **Hiệu Ứng Đặc Biệt**
- **Hoa đào nở** khi hiện chữ "HAPPY NEW YEAR"
- **Hoa mai nở** khi hiện số "2026"
- **Cánh hoa rơi** với hiệu ứng xoay nhẹ nhàng

### 🏮 **Không Khí Tết**
- **Câu đối Tết** hai bên: "XUÂN AN KHANG ĐỊNH CÁT" - "TÂN NIÊN THỊNH VƯỢNG PHÁT TÀI"
- **Chữ nhấp nháy** với hiệu ứng glow
- **Tỏa sáng** khi pháo hoa nổ
- **Âm thanh** pháo nổ sống động

### 🎮 **Điều Khiển**
| Phím | Chức Năng |
|------|-----------|
| `ENTER` | Chuyển chế độ (Pháo hoa / Chữ / Số) |
| `SPACE` | Bắn thêm pháo hoa |
| `A` | Bật/tắt chế độ tự động |
| `R` | Reset chương trình |

## 🛠️ Cài Đặt & Biên Dịch

### **Yêu Cầu**
- **SFML 2.5.x** ([Download](https://www.sfml-dev.org/download.php))
- **Compiler hỗ trợ C++11** (GCC, MSVC, Clang)


### **Biên Dịch với g++**
`bash
g++ -o TetFireworks.exe main.cpp -lsfml-graphics -lsfml-window -lsfml-system -lsfml-audio`
